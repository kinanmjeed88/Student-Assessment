# النسخ الاحتياطي لتوقيع Android

## ما يجب حفظه

احتفظ بالملفات والمعلومات التالية في مدير كلمات مرور موثوق أو وسيط تخزين مشفّر خارج المستودع:

| العنصر | الغرض | مكان الحفظ المناسب |
|---|---|---|
| `student-record-release.keystore` | إثبات ملكية توقيع تطبيق Android | مساحة تخزين مشفرة أو مدير كلمات مرور يدعم الملفات |
| كلمة مرور ملف Keystore | فتح ملف التوقيع | مدير كلمات المرور |
| كلمة مرور المفتاح الداخلي | التوقيع على إصدارات APK الجديدة | مدير كلمات المرور |
| اسم المفتاح `student-record-release` | تحديد المفتاح داخل Keystore | ملف الإعداد غير السري أو مدير كلمات المرور |

## قواعد مهمة

لا ترفع ملف Keystore أو كلمات المرور أو قيمة Base64 إلى المستودع. تبقى الأسرار ضمن **GitHub Actions secrets** بالأسماء `ANDROID_KEYSTORE_BASE64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_PASSWORD`.

يجب الاحتفاظ بنسختين مشفرتين من ملف Keystore في موقعين مختلفين. فقدان هذا المفتاح يمنع نشر تحديثات جديدة بنفس هوية التطبيق في متجر Google Play.

## استعادة إعداد التوقيع

عند استخدام جهاز جديد، أنشئ قيمة Base64 من ملف Keystore ثم حدّث سر GitHub المناسب:

```bash
base64 -w 0 student-record-release.keystore
```

بعد تحديث الأسرار، شغّل سير العمل **Build Android APK** من صفحة GitHub Actions لإنشاء APK موقّع جديد.
