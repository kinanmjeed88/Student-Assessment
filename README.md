# سجل الطالب

تطبيق Android عربي يعمل محليًا لإدارة الطلاب بحسب الصف والشعبة. يتيح تسجيل الحضور والغياب، إدخال الدرجات عبر حقول تقييم مرنة، توثيق السلوك والملاحظات، وتصدير التقرير المدرسي أو ملف الطالب إلى PDF بحجم A4 وExcel.

## الوظائف المنفذة

| القسم | ما يتيحه التطبيق |
|---|---|
| الطلاب | إضافة الطالب وربطه بالصف والشعبة والبحث عنه وعرضه كقائمة شُعب أو بطاقات منظمة |
| ملف الطالب | عرض ملف تفصيلي يضم الدرجات والحضور والسلوك والملاحظات وبيانات ولي الأمر |
| الحضور | تحديد الصف والشعبة والتاريخ، ثم تعيين الجميع حاضرًا أو تعديل الحالة لكل طالب |
| الصفوف والشُعب | إضافة صفوف مثل «الأول» وشُعب مثل «أ» و«ب» قبل إدخال الطلاب |
| التقارير | إنشاء PDF بحجم A4 أو Excel متعدد الأوراق للمدرسة أو تصدير سجل فردي للطالب |
| الإعدادات | حفظ اسم المدرسة واسم المدرس والعام الدراسي والمرحلة التعليمية |

> تحفظ البيانات على الجهاز باستخدام التخزين المحلي. لذلك من المستحسن استخدام تصدير Excel بصورة دورية للاحتفاظ بنسخة من السجلات.

## بناء APK من GitHub Actions

يعمل سير العمل الموجود في `.github/workflows/build-apk.yml` تلقائيًا عند رفع أي تغيير إلى فرع `main`، ويمكن تشغيله يدويًا من تبويب **Actions** في GitHub.

| الخطوة | الإجراء |
|---|---|
| 1 | ارفع التغييرات إلى فرع `main` أو افتح **Actions** ثم اختر **Build Android APK** واضغط **Run workflow**. |
| 2 | انتظر انتهاء مهمة **Build installable debug APK** بنجاح. |
| 3 | افتح صفحة تنفيذ المهمة ثم قسم **Artifacts**. |
| 4 | نزّل الملف باسم `student-record-apk-<رقم التنفيذ>` وفك الضغط عنه. |
| 5 | ثبّت ملف `app-debug.apk` على هاتف Android بعد السماح بالتثبيت من مصدر موثوق عند طلب النظام. |

ينتج السريان الحالي APK تجريبيًا موقّعًا بمفتاح التصحيح، وهو مناسب للاختبار والتثبيت الداخلي. يتطلب إصدار متجر Google Play لاحقًا إعداد مفتاح توقيع إصدار آمن خارج المستودع.

## التشغيل المحلي للمطور

```bash
pnpm install
pnpm dev
```

وللتحقق من الأنواع قبل الرفع:

```bash
pnpm exec tsc --noEmit
```
